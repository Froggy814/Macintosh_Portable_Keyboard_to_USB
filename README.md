# Macintosh_Portable_Keyboard_to_USB

So this is the second ever, Mac Potable Keyboard to USB ever! It does a simple task. Takes a Mac Portable Keyboard and interprets it's ==Matrix== And viola, through the magic of... BLE! And USB! WOW this can now communicate with anything! No wires needed, well... Unless you want to not hook your Keyboard up to the ESP32 Dev board, those wires are needed.

The install instructions are in with the .ino file. (The file full of human made code BTW) If you have any troubles don't hesitate to make a complaint! I will try and help in any way I can!
